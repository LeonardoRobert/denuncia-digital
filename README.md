**Projeto Extensionista — UNIG EAD — 5º Período**  
Tema Integrador V — Direitos Humanos e o Universo Digital  
Alinhado ao **ODS 16** — Paz, Justiça e Instituições Eficazes

---

## 📁 Arquivos do projeto

| Arquivo | Descrição |
|---|---|
| `index.html` | App completo (HTML + CSS + JS) |
| `manifest.json` | Configuração do PWA (instalação no celular) |
| `sw.js` | Service Worker (funcionamento offline) |
| `icon-192.png` | Ícone do app (192x192) |
| `icon-512.png` | Ícone do app (512x512) |

---

## 📱 Como instalar no celular (Android)

1. Abra o link do GitHub Pages no **Chrome**
2. Toque no menu (⋮) → **"Adicionar à tela inicial"**
3. Confirme — o app aparece na tela como qualquer outro!

## 🗄 Banco de dados

- **Plataforma:** Supabase (PostgreSQL)
- **Tabelas:** `denuncias`, `pesquisa_perfil`
- **Acesso:** Anônimo, sem coleta de dados pessoais (LGPD)

---

## 📊 Funcionalidades

- ✅ Pesquisa de perfil anônima (faixa etária, período de uso, apps)
- ✅ Cadastro anônimo de violações de direitos digitais
- ✅ Dashboard dinâmico com gráficos em tempo real
- ✅ Banco de dados compartilhado entre todos os usuários
- ✅ Instalável como app no celular (PWA)
- ✅ Funciona offline (Service Worker)
